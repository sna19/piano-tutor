# Источники нот и лицензии

## Бах — Mutopia Project
149 пьес (`src/lib/content/pieces/bach/*.abc`, каталог — `bach.generated.json`) получены из набора
[Mutopia Project](https://www.mutopiaproject.org/): MIDI каждой пьесы (LilyPond пишет его точно, без
«человеческого» темпа) переведён в ABC скриптом `scripts/midi2abc.mjs` и сверен с MIDI нота в ноту
(`scripts/import-mutopia.mjs`, функция `verify`). Пьесы, где расходится больше 1% нот, не взяты; где расходятся
единицы нот — взяты с пометкой «черновик» (`draft`), их надо сверить с изданием.

Лицензии — у каждой пьесы в каталоге (`source.license`): большинство — Public Domain, часть — Creative Commons
Attribution-ShareAlike (3.0/4.0). ABC, полученный из файла CC BY-SA, — производная работа и распространяется на тех же
условиях; источник и набор указаны на экране пьесы.

Что теряется при переводе из MIDI: повторы (пьеса записана одним проходом), украшения (записаны короткими нотами),
аппликатура, лиги фразировки, динамика. Это можно добавить позже из LilyPond-исходников.

Повторить импорт: `node scripts/import-mutopia.mjs <список.json> [кэш]` — список собирается из поиска Mutopia по
композитору BachJS (скрипт сбора — в истории коммита этапа 1).
