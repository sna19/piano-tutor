# Контекст проекта для Claude Code

## Что это
Личное приложение одного ученика (владельца репозитория) для обучения игре на пианино: программа по уровням,
задания на день, ноты со звуком (Бах и другая классика), аккорды, backing tracks для импровизации (джаз, блюз),
учебник по направлениям. Подробно — docs/CONCEPT.md, порядок работ — docs/PLAN.md, решения — docs/DECISIONS.md.

## Среда
- Платформа и деплой — общие правила `/work/CLAUDE.md` (Docker на NAS, `/health`, данные в `/data`, не root,
  `chmod -R a+rX,go-w /app`).
- Клиент — прежде всего iPhone/iPad (PWA), также браузер на компьютере.
- Один пользователь, своя авторизация не нужна (её делает Caddy-замок владельца).

## Соглашения
- Документация и обсуждение — на русском. Код, идентификаторы, коммиты — на английском.
- Новое решение → запись в docs/DECISIONS.md (дата, решение, причина).
- Маленькие шаги: рабочее состояние после каждого коммита; push после каждого коммита.
- Контент (пьесы, сетки, уроки, главы учебника) — в репозитории как данные (`src/lib/content/`); прогресс ученика —
  в SQLite (`/data`).
- Только материал в общественном достоянии или свой. Ноты, записанные по памяти, — с пометкой `draft: true`, пока
  не сверены с изданием (IMSLP).
- Мобильный интерфейс в приоритете; светлая и тёмная тема.

## Стек и команды
SvelteKit (adapter-node, TypeScript, Svelte 5) + SQLite (better-sqlite3, миграции Drizzle в `drizzle/`), ноты и
звук — abcjs.

```sh
npm run dev           # разработка, данные в ./data
npm run check         # типы
npm test              # vitest
npm run db:generate   # миграция после правки src/lib/server/schema.ts
```
